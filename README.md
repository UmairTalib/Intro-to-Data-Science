# Intro to Data Science: course assignments

My solutions to two assignments from the course Introduction to Data Science at the University of Central Punjab, Lahore, in spring 2021, during my bachelor's studies in computer science. The PDFs are the assignment sheets from the course, and the notebooks hold my solutions.

| Assignment | Topic | Sheet | Solution |
| --- | --- | --- | --- |
| 1 | Python basics: temperature conversion, divisibility checks, minimum and maximum of a list, mean, median, mode and variance without built-in functions, word counts with dictionaries, and a ticket price lookup | [PDF](Assignemnt%201%20_Data_Science.pdf) | [`Assignment1.ipynb`](Assignment1.ipynb) |
| 2 | NumPy: creating, slicing, splitting, sorting and changing arrays | [PDF](Assignment%202.pdf) | [`assignment2.ipynb`](assignment2.ipynb) |

To open the notebooks, install Jupyter and NumPy (`pip install notebook numpy`) and run `jupyter notebook` in this folder.
